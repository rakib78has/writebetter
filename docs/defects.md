# Defects

Defects found during development, how they were found, and what fixed them. Each fix has a regression test, so the defect can't silently return. Known limitations of the grammar engine (things it misses) are listed in [grammar-engine.md](grammar-engine.md) instead.

| ID      | Found in    | Defect                                                                                       | Found by                             | Severity | Fix                                                                               | Status            |
| ------- | ----------- | -------------------------------------------------------------------------------------------- | ------------------------------------ | -------- | --------------------------------------------------------------------------------- | ----------------- |
| DEF-001 | Milestone 2 | An empty `?tab=` parameter was read as tab 0, because `Number('')` is 0                      | WB-INT-015                           | Low      | Parameter must be a run of digits (fa21c7f)                                       | Fixed             |
| DEF-002 | Milestone 3 | Fix grammar "corrected" HTML in text: `<img src=x>` became `<i mg sac=x>`                    | WB-SEC-013                           | Medium   | HTML/XML tags added to protected text (c1e1058)                                   | Fixed             |
| DEF-003 | Milestone 3 | Names were auto-"corrected": "Rakib" → "Rabbi", "Siobhan" → "Sideman"                        | Accuracy exploration; WB-INT-026     | High     | Spelling fixes to capitalised words are held for review (c1e1058)                 | Fixed             |
| DEF-004 | Milestone 3 | A selected fragment's first word was capitalised ("their is…" → "Their is…")                 | WB-E2E-018                           | Medium   | First word never auto-capitalised, except "i" (c1e1058)                           | Fixed             |
| DEF-005 | Milestone 3 | A path like `src/popup/App.tsx` was protected as two overlapping ranges                      | WB-UNIT-028                          | Low      | One pattern for identifiers and paths (c1e1058). No user impact.                  | Fixed             |
| DEF-006 | Milestone 4 | Dark mode showed a white background below the popup content                                  | Visual review (screenshots)          | Low      | Body background themed (b58aa53)                                                  | Fixed             |
| DEF-007 | Milestone 4 | Change view ran removed and added words together ("waswere")                                 | Visual review (screenshots)          | Low      | Spacing and padding on change marks (b58aa53)                                     | Fixed             |
| DEF-008 | Milestone 5 | Replacing a whole rich-text selection deleted bold text and links and multiplied blank lines | Chromium probe before implementation | High     | Fixes applied one word at a time (7991675)                                        | Fixed (by design) |
| DEF-009 | Milestone 5 | Lexical applied an edit to its stale selection, corrupting text ("Hi all, thewere")          | WB-E2E-023 (Lexical)                 | Critical | Wait for `selectionchange` before each edit; verify after each and stop (7991675) | Fixed             |
| DEF-010 | Milestone 5 | Indentation in a page's HTML source appeared in text read from an editor                     | WB-E2E-023 (plain contenteditable)   | Medium   | Text read as displayed, whitespace collapsed (7991675)                            | Fixed             |
| DEF-011 | Milestone 5 | Rich confirmation said "Make 1 this change"                                                  | WB-UI-034                            | Low      | Wording fixed (7991675)                                                           | Fixed             |
| DEF-012 | Milestone 3 | harper.js's Node loader mangles Windows paths (`/C:/…`) (upstream; affects tests only)       | Writing the accuracy suite           | Low      | Tests load the WebAssembly as a `data:` URL                                       | Worked around     |

Severity: **Critical** corrupts or loses user text; **High** changes meaning without asking; **Medium** wrong or confusing output the user can see and fix; **Low** cosmetic or no user impact.
